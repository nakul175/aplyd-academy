Owner: Nakul Jain · Last reviewed: 2026-10-08 · Update when code reads a new variable, a deploy script adds one, or the Worker bindings change.

Names only; no values anywhere in Git. The machine-readable list is [`.env.example`](../../.env.example) at the repository root (made trackable by an `!.env.example` line in `.gitignore`). Derived from code and deploy files on 2026-10-08; re-derive with `grep -rhoE "process\.env\.[A-Z_]+" app lib scripts deploy`.

## What the application needs

| Name | Kind | Read by | Required | Notes |
|---|---|---|---|---|
| `DB` | Worker D1 binding | every `app/api/**/route.ts` via `env.DB` | Yes | Declared in the generated `dist/server/wrangler.json` (database name `site-creator-d1`, a placeholder id). On the droplet it is a local SQLite file under `/var/lib/aplyd-academy/state`. Missing `DB` returns 503 from the routes. |
| `ACADEMY_DUMMY_PARTNER_URL` | Worker var | `app/api/partner/links/route.ts`, `deliver/route.ts` | No | Local dummy-partner demo only; a loopback URL is asserted in `lib/academy-partner-dummy-service.ts`. Unset means "dummy partner not running". |

No identity secret exists in the app. Identity arrives as three request headers (`oai-authenticated-user-id`, `-email`, optional `-full-name`) from the host; on the droplet Caddy sets them (deploy/Caddyfile).

## Runtime and tooling

| Name | Set by | Purpose |
|---|---|---|
| `SITES_RUNTIME_ROOT` | systemd unit `deploy/aplyd-academy.service` (`/var/lib/aplyd-academy/runtime`) | Where wrangler logs and registries go (`scripts/sites-env.mjs`) |
| `WRANGLER_SEND_METRICS`, `WRANGLER_WRITE_LOGS`, `CLOUDFLARE_CF_FETCH_ENABLED` | `scripts/sites-env.mjs` defaults (`false`) | Keeps telemetry and Cloudflare fetches off |
| `WRANGLER_LOG_PATH`, `WRANGLER_REGISTRY_PATH`, `MINIFLARE_REGISTRY_PATH` | `scripts/sites-env.mjs` | Local scratch directories |
| `SITES_INSTALL_*`, `SITES_PNPM_*`, `SITES_PROJECT_ROOT`, `SITES_ENV_READY` | install and build scripts | Install/build helpers |

## Provisioning (shell variables for one `provision.sh` run)

| Name | Secret | Meaning |
|---|---|---|
| `SAHA_HOST` | no | Public host name, for example `<app>.<ip-dashed>.sslip.io` |
| `SAHA_FIRST_USER` | no (an email) | First person allowed to sign in |
| `SAHA_GIT_TOKEN` | **yes** | Read-only GitHub token; omit to use a deploy key. Stored on the droplet at `/etc/saha/aplyd-academy.git-token` (mode set by provision.sh) |

## Demo and test harness

`DEMO_*`, `PORT`, `HOST` (scripts/demo/*) and `ACADEMY_URL`, `ACADEMY_LOCAL_URL`, `ACADEMY_QA_*`, `ACADEMY_PLAYWRIGHT_MODULE` and other `ACADEMY_*_OUT` paths (tests/*) are local-only. They must point at a local worker, never at the hosted Site or droplet (CLAUDE.md).
