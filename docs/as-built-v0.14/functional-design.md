# Aplyd Academy v0.14 candidate: functional design

This describes the locally integrated M4 candidate. Published baseline is v0.13, main `8a769a24415169ea24b45b6f97ae89e050c99b19`; native v0.14 publication remains pending. Local browser acceptance is complete within the bounded scopes below. The sprint deadline is 6 October 2026, 08:47 IST.

## Before enrollment

**FS-M4-01 — Resolve the displayed edition.** The learner sees prerequisites and the passing rule beside the existing course outcomes. The section uses the course snapshot already selected by LearningView, only before enrollment. Global courses use their exact archived policy wording. Private courses advertise only the existing 70-point / 0–4 / 100 total-weight / all-critical-gates contract. Unknown or mismatched references do not borrow another edition.

**FS-M4-02 — Explain unavailable policy.** Missing or unsupported private policy leaves the own edition prerequisites readable and the passing rule unavailable. The read model checks integer rubric weights of 1–97 summing to 100 and the supported critical-gate shape. Existing authoring/scoring enforce the publication and assessment contract. This section grants no enrollment authority, changes no pass standard and introduces no saved preference. Existing enrolled and paused/unavailable-content journeys remain authoritative.

## Weekly learning review

**FS-M4-03 — Show one review of the saved own plan.** A compact review replaces the old combined weekly completion statistic in My learning plan. The saved timezone defines Monday–Sunday; unsaved goal, budget or timezone edits do not change it. The observation time and the summary must agree on today and week boundaries.

**FS-M4-04 — Distinguish intentions and evidence.** The view separately counts non-skipped dated activities and intended minutes, retained plan items backed by saved lesson/submission/reflection actions, and self-reported private practice. Completion week comes from the projected saved completion timestamp, independently of planned date. A saved submission does not mean a pass; reflection does not verify job impact. Historical completion remains visible when current access or a pin is unavailable. Missing or future completion dates are excluded from weekly completion and identified for review. Coverage is retained own plan items, not every course action.

**FS-M4-05 — Find existing open work.** A native disclosure shows up to six blocked, undated or earlier open items, ordered by blocked status, earlier date, date and ID. Each button focuses the corresponding existing own activity card. Attention counts overlap; they are not another total. The existing goal form and activity list remain in the same journey.

**FS-M4-06 — Download a private aggregate.** Two deliberate actions generate JSON or standalone printable HTML on the device. A fresh whitelist contains only week dates, saved timezone, numeric counts and fixed explanatory text. It excludes goals, notes, titles, evidence bodies, contacts, account/workspace/task/enrollment IDs, content pins and revision metadata. Filenames use only the week dates. Export requires an accepted own projection, no loading/read error and no pending save; an inactive member may export accepted own retained history. Invalid derivation has no export. An export error leaves the plan unchanged. The pending-save guard is source-inspected; no protected write was started to exercise it.

## Partner meeting worksheet

**FS-M4-07 — Download fixed discussion material.** The existing personal ecosystem inspector offers one printable worksheet for each exact key `agri`, `msme` and `public`. Its only input is that key. It contains the fixed global learning context and exclusions, 16 definitions of existing local return fields, seven open decisions, eight boundary checks and checksum-verified original Library references. Every authority flag is false. It contains no learner, workspace, enrollment, choice, receipt or current progress value, and creates no consent, recipient, connection, signature or acknowledgement.

**FS-M4-08 — Preserve the existing scope boundaries.** Health has no worksheet or clinical mapping. Shared workspaces do not expose the personal inspector. Its existing generic JSON brief remains separate. Existing local choices and historical simulated receipts remain governed by the server/domain contract; downloading this document never grants or withdraws a choice. The worksheet establishes no live exchange or institutional approval.
