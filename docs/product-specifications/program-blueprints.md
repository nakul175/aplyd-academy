# Aplyd Academy Example Program Blueprints

These proposed pathways demonstrate how the shared platform can deliver specific role-based promises. They are curriculum and assessment examples for review, not approved training, sector advice or selected pilot programs. All exercises use fictional records and supported approved tools.

Version 0.1 dated 5 October 2026. Each pathway adapts the common foundation while retaining the same responsible-AI assessment dimensions.

## Shared foundation

| Activity | Learner action | Evidence |
|---|---|---|
| Recognize the task | Describe a useful work task and intended audience | Task statement and suitability choice |
| Protect information | Classify inputs and replace restricted information | Input classification and synthetic replacement |
| Direct the tool | Provide context, constraints and desired format | Instructions and generated draft |
| Verify the result | Detect a planted unsupported claim or error | Source check or calculation check |
| Exercise judgment | Revise, decline or escalate as appropriate | Final work and explanation |
| Apply and reflect | Use the capability in a permitted setting | Follow-up evidence without unnecessary sensitive data |

Estimated learning effort, language and delivery mode must be set after learner research. Each can combine self-paced activities with cohort discussion and facilitator support.

## Farmer pathway

**Promise:** Organize a fictional farm activity record and prepare a clear, verified set of questions for an agricultural expert.

1. Read a simple synthetic activity and expense record.
2. Organize it into a consistent table using a supported tool.
3. Ask AI to summarize patterns and identify missing information.
4. Check arithmetic and identify a deliberately unsupported recommendation.
5. Prepare an expert question list that includes location/context gaps and avoids acting on unverified consequential advice.

Assessment evidence includes source record, organized table, instructions, draft, checks, revised summary and expert questions. Domain experts approve the scenario and scoring. The credential describes recordkeeping and information-evaluation capability, without asserting professional agricultural qualification.

## MSME owner pathway

**Promise:** Produce an accurate customer response and a reusable daily-work checklist from fictional business information.

1. Review an example customer's request and fictional order policy.
2. Identify information that should not be uploaded to an external tool.
3. Create a draft response using only permitted synthetic inputs.
4. Check the response against the supplied policy and correct an invented promise.
5. Produce a daily operations checklist and explain which steps require human confirmation.

Assessment evidence includes input classification, prompt, draft response, policy checks, corrected response and checklist. Quality measures include clarity, accuracy and usefulness; responsible-use criteria include confidentiality and checking commitments.

## Bureaucrat pathway

**Promise:** Produce a clear administrative brief from supplied permitted reference material, with traceable facts and human review points.

1. Identify the brief's purpose and intended reader.
2. Separate shareable sample material from restricted examples.
3. Ask AI to draft a summary using supplied material.
4. Find an unsupported reference and missing qualification.
5. Correct the brief, identify source passages and specify review required before official use.

Assessment evidence includes source mapping, instructions, draft, errors found, revised brief and review rationale. The exercise does not use real confidential administrative files. The credential names drafting and verification capability, not authority to issue decisions.

## Reference assessment rubric

| Dimension | Proposed weight | Passing evidence |
|---|---|---|
| Task quality | 40 | Work is coherent and meets the scenario's objective |
| Verification | 25 | Important claims or calculations checked; planted error identified |
| Information handling | 20 | Restricted input avoided and safe substitute used |
| Judgment | 15 | Limits explained and appropriate human review or escalation identified |

Reference pass is at least 70 of 100 with every critical criterion met. The scenario defines critical failures explicitly, such as exposing restricted information or accepting the planted consequential recommendation without required verification. Each program publishes its final policy before enrollment. Illustrative weights are not universal Academy standards.

## Evaluation and follow up

Record comparable pre- and post-task performance where feasible. After completion, ask whether the learner used the capability and invite minimal evidence or a structured reflection. Do not require confidential workplace material. Facilitators can discuss anonymized challenges and direct learners to a refresher.

Review pilot results by learner group, language and access needs. A pathway's usefulness must be assessed independently of enthusiasm for AI or a completion certificate.
