# Private content studio · v0.6

Current workspace owners can copy one of the three fictional practice seeds, edit ordinary fields and ask another current owner to review it. The author cannot approve their own draft. The assigned reviewer checks sources, answers, the practical rubric, information handling and clear instructions. Approval binds the exact document revision and canonical SHA256. Publication rechecks current independent reviewer permission and the future content-review date.

Each published version is immutable and belongs to one workspace. **Offer in new cohort** opens cohort creation with that exact version selected. Cohorts and enrollments retain their content reference; a replacement never changes an existing learner's lessons, answer key, rubric or record. Retirement or the content-review date closes new enrollment; pause a cohort separately when continuing learning must stop. Private content never joins the global catalog.

The studio preserves unfinished drafts and flags issues before review. The bounded structure contains three lessons, nine knowledge checks, seven practical response fields, four weighted rubric criteria and three critical gates. Adult English fictional practice, role/context, IDs, claim exclusions and pass/appeal policy remain fixed. The farmer seed's intentional copied transaction is preserved and explicitly annotated in private copies, with its checked answer unchanged.

Own unsent editing and review input stays in workspace-keyed memory during tab changes and authority refresh. A full page reload can lose unsent input. Conflicts show the current saved draft and require explicit discard/reload or an acknowledged rebase. Inputs freeze during a save. Published and archived screens show the canonical saved document; retained own unsent text is separately labelled. Losing owner permission removes former server bodies from the client view.

Any current owner can archive an unpublished draft, including one left by a former owner. Archive is terminal: it preserves document, approval history and lifecycle events, releases the active slot and cannot publish or reopen. Limits are four active drafts, 24 retained drafts and eight retained publications. Retiring publications or archiving drafts retains their quota history. There is no bulk deletion or quota-reset workflow.

A document fits 65,536 UTF-8 JSON bytes. Authoring plus reserved final archive/retirement growth fits 650,000 bytes. The aggregate admission check also reserves all open support withdrawals. Current permissions remain required for protective actions. No schema migration or external content store was added.

The complete functional delta, low-level contract, structured data dictionary and operator acceptance checklist are in [as-built-v0.6](as-built-v0.6/README.txt). Executed local verification is in [test-evidence.json](test-evidence.json). The operator checklist is a separate manual validation plan; unchecked items are not reported as passed.

This release provides private nonaccredited practice authoring. Sector approval, real learner pilots, operational staffing, recognized issuance, reviewed translations, offline/assisted journeys, hosted participant access, live AI and actual ecosystem exchange still need their own implementation and evidence.
